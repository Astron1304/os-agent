# 🤖 OS-Agent

**Мой маленький ИИ-агент для работы с файлами и операционной системой**

OS-Agent — это локальный ИИ-ассистент на базе LangGraph, который умеет не только вести диалог, но и **реально взаимодействовать с твоей операционной системой**: читать и писать файлы, искать информацию, управлять папками и даже искать актуальные данные в интернете.

## ✨ Возможности

### 🧠 Умная архитектура
- **LangGraph + SQLite** — агент помнит контекст всех предыдущих диалогов (память сохраняется между запусками)
- **Поддержка нескольких провайдеров** — Ollama (локально), OpenAI, Anthropic, OpenRouter
- **Два режима ответа** — потоковый (чанками, в реальном времени) и полный
- **Подробное логирование** — все действия агента и инструментов записываются в `latest.log`

### 🛠 Инструменты (Tools)
Агент может использовать следующие инструменты для работы с ОС:

| Инструмент | Описание |
|---|---|
| 🔍 `search_tool` | Поиск актуальной информации в интернете (DuckDuckGo) |
| 📖 `read_file` | Чтение содержимого любого текстового файла |
| ✍️ `write_file` | Запись текста в файл (создаёт папки, если их нет) |
| 🔎 `search_in_files` | Рекурсивный поиск текста во всех файлах папки |
| 📁 `list_files` | Просмотр содержимого директории |
| 📂 `create_directory` | Создание папок (включая вложенные) |
| 📋 `copy_files` | Копирование файлов между директориями |
| 🚚 `move_files` | Перемещение файлов |
| 🗑️ `delete_objects` | Удаление файлов и папок |

### 🛡️ Безопасность
Встроены защитные механизмы, чтобы агент случайно не навредил системе:
- ❌ Запрет на удаление объектов из **рабочей директории агента**
- ❌ Запрет на перемещение файлов из рабочей директории
- Все пути нормализуются через `Path.resolve()` для предотвращения ошибок

## 🚀 Установка

### 1. Клонируй репозиторий
```bash
git clone https://github.com/Astron1304/os-agent.git
cd os-agent
```

### 2. Создай виртуальное окружение
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 3. Установи зависимости
```bash
pip install -r requirements.txt
```

### 4. (Опционально) Установи Ollama для локальной работы
Если хочешь использовать локальные модели (бесплатно и приватно):
1. Скачай [Ollama](https://ollama.com/)
2. Запусти модель:
   ```bash
   ollama pull llama3
   ```

## ⚙️ Настройка

Создай файл **`config.json`** в корне проекта на основе шаблона:

```json
{
  "provider": "ollama",
  "model": "llama3",
  "api_key": "your_api_key_here",
  "temperature": 0.1,
  "memory_file": "memory.sqlite",
  "preferred_dir": "C:/Users/YourName/Documents",
  "o_format": "chunk",
  "agent_config": {
    "configurable": {
      "thread_id": "default"
    }
  }
}
```

### Параметры:
- **`provider`** — один из: `ollama`, `openai`, `anthropic`, `openrouter`
- **`model`** — название модели (например, `llama3`, `gpt-4o`, `claude-3-5-sonnet-20241022`)
- **`api_key`** — твой API-ключ (не нужен для Ollama)
- **`temperature`** — "креативность" модели (0 = максимально точно, 1 = максимально креативно)
- **`preferred_dir`** — рабочая директория, где агент будет работать с файлами
- **`o_format`** — `"chunk"` (потоковый вывод) или `"whole"` (полный ответ)

> ⚠️ **Важно:** файл `config.json` уже добавлен в `.gitignore`, чтобы твой API-ключ случайно не попал на GitHub.

## ▶️ Запуск

```bash
python main.py
```

После запуска агент поприветствует тебя и будет ждать команд. Чтобы выйти, введи `выход`, `exit` или `quit`.

### Примеры запросов:
- *"Привет, кто ты и что умеешь?"*
- *"Покажи содержимое папки C:/Projects"*
- *"Создай папку 'test' в моей рабочей директории и запиши туда файл hello.txt с текстом 'Привет, мир!'"*
- *"Найди во всех файлах моей рабочей директории слово 'важно'"*
- *"Какая сейчас погода в Москве?"* (использует поиск в интернете)
- *"Скопируй файлы a.txt и b.txt из папки Downloads в папку Backup"*

## 📂 Структура проекта

```
os-agent/
├── main.py              # Точка входа, инициализация агента и диалога
├── agent.py             # Логика формирования ответов (чанками и полностью)
├── tools.py             # Все инструменты агента (работа с файлами, поиск)
├── log_config.py        # Настройка системы логирования
├── config.json          # Конфигурация (в .gitignore!)
├── requirements.txt     # Зависимости Python
├── memory.sqlite        # База памяти агента (в .gitignore!)
├── latest.log           # Текущий лог (в .gitignore!)
├── logs/                # Архив старых логов (в .gitignore!)
└── LICENSE              # Лицензия MIT
```

## 🧪 Стек технологий

- **Python 3.10+**
- **[LangGraph](https://github.com/langchain-ai/langgraph)** — оркестрация агента и память
